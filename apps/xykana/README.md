# Xykana

This folder contains the Xykana Phase 1 application. It's an offline-first React + TypeScript PWA scaffold with Dexie IndexedDB and an SRS engine.

To run:

cd xykana
npm install
npm run dev

Build:

npm run build

Notes:
- Core offline features: Hiragana/Katakana lists, Review flow with local SRS, Dexie DB.
- This is initial Phase 1 implementation. Add more content under src/data.
