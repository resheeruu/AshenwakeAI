Support

Open a case from Discord, track it in the dashboard, or read the documentation first.

Open Dashboard Read the docs

Open a support case

Cases are created in Discord with the bot's support command. Staff respond in the ticket channel, and the dashboard shows the case status, summary and last update.

Track cases in the dashboard

Administrators can follow every open, escalated and resolved case for their servers under Settings → Support, and change status with an audited transition.

Documentation

Setup, providers, authentication and deployment guides live in the documentation. Most configuration questions are answered there.

Bug reports

Report issues through the GitHub repository, including the version shown on the status page and the steps to reproduce.

Before you open a case

  • Check the status page — a degraded health gate explains most outages.
  • Confirm which server and section you were changing when it failed.
  • Include the exact error text; messages are redacted of secrets before they are logged, so it is safe to paste.
