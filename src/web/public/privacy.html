Privacy Policy

How AshenAI handles your data — what is collected, why, and where it goes.

Last updated 2026

Data handling

AshenAI processes the data required to provide AI functionality. User conversations are stored temporarily for context so follow-up messages make sense. We do not sell personal data.

Discord data

Discord data is accessed only as necessary for bot functionality and server configuration. Guild IDs and user IDs are used for authorization — deciding which servers an operator may read or change — and for correlating audit entries.

AI providers

Requests to AI providers are mediated through secure server-side connections. Provider credentials are stored encrypted and are never returned to the browser, logged, or included in error messages.

Logs

Audit logs and usage statistics are maintained for operational purposes. IP addresses and timestamps are recorded for security auditing. Log messages are passed through a redaction step before they are written, so secrets and tokens that slip into a message body do not land in the log file.

Cookies and sessions

Sign-in state is held in an HTTP-only cookie that JavaScript cannot read. Requests that mutate data carry a CSRF header, sessions expire on a fixed timeout, and an operator can revoke any other session from the Security section of the dashboard.

What we do not do

  • We do not sell or rent personal data.
  • We do not expose provider API keys to the client.
  • We do not run dashboard actions as background jobs without a server-side role check.
