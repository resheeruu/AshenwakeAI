Honest scope

Automation rules are stored and evaluated by the bot — the dashboard never executes them, so a compromised session cannot start a shadow job. Support cases are created in Discord and only their status is edited from the web. Everything you change in the dashboard is written through a role-gated, CSRF-protected API and recorded in an audit trail.
