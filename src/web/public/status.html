What this means

Overall is the health gate: it passes when the database is reachable and startup preflight did not block. A degraded overall status means the API returns 503 with a JSON body rather than silently claiming to be healthy.

Discord gateway health is intentionally not shown here because the public health endpoint does not measure it. Authenticated operators can see the full component breakdown inside the dashboard.
