What is AshenAI?

AshenAI is an AI-powered Discord assistant and Control Center. It manages Discord servers, provides AI conversation, and offers server administration tools.

Account Types

Local accounts use AshenAI username/password authentication.

Discord/Google accounts authenticate through OAuth. After successful authorization, you are automatically signed in.

Roles:

  • User — Personal AI features, account management, Help
  • Admin — Manage authorized Discord servers, server diagnostics, utilities
  • Owner — Full AshenAI system control, providers, backups, audit

Discord Server Management (Admin)

Admins can manage Discord servers they are authorized for. Use the Servers section to view and configure authorized servers.

Examples:

  • Inspect server channels, categories, and roles
  • Diagnose server configuration problems
  • Create and organize channels
  • Moderate where Discord permissions permit

Destructive changes require confirmation. AshenAI respects both its own permissions and your Discord permissions.
