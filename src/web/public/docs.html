Getting started with AshenWakeAI.

Getting Started

Add AshenWakeAI to your Discord server and configure it through the dashboard.

Dashboard

Manage your server settings, AI providers, models, and configurations through the web dashboard.

Authentication

Login with username/password or link Discord/Google OAuth. MFA is supported for enhanced security.

Provider Management

Configure AI providers including Google Gemini, Groq, OpenRouter, and local models. Use the provider wizard to add new providers.

Free AI Mode

Prefer providers/models legitimately available under free or no-cost access. Free access may be subject to provider quotas.

Provider Categories

Free, Free-tier, Trial/Credit, Paid, Local, and Custom providers are supported.

Deployment

Deploy on Render, Docker, Wispbyte, VPS, or Termux. See the deployment guide for host-specific configuration.
