# Performance Optimization & Scalability Skill 🚀

Gunakan instruksi ini untuk meningkatkan kecepatan & efisiensi:
1. **Non-blocking Execution**: Gunakan operasi asynchronous (`async/await`) dan hindari pemanggilan sinkron yang mengunci event loop.
2. **Parallel Processing**: Gunakan `Promise.all()` untuk operasi I/O independen yang dapat berjalan secara bersisian.
3. **Efisien Memory & Query**: Hindari loop bernested berat dan masalah N+1 query pada database.
4. **Caching Strategy**: Terapkan memoization atau caching untuk hasil komputasi yang sering diakses.
