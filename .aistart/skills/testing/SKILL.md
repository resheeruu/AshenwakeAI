# Testing & Quality Assurance Skill 🧪

Gunakan instruksi ini untuk penulisan tes:
1. **Runner Detection**: Identifikasi framework tes proyek (`jest`, `vitest`, `pytest`, `mocha`).
2. **Skenario Komprehensif**: Tulis tes untuk Happy Path (kasus normal) dan Edge Cases (input null/kosong, error jaringan, nilai ekstrim).
3. **Isolasi Modul**: Gunakan mock/stub jika modul berinteraksi dengan API eksternal atau database.
4. **Eksekusi & Verifikasi**: Jalankan `run_command` untuk memastikan seluruh suite tes LULUS (PASS).
