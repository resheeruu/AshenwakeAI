# Premium UI/UX & Visual Design Skill 🎨

Gunakan instruksi ini saat membuat atau memperbarui antarmuka pengguna:
1. **Estetika Premium**: Gunakan palet warna terkurasi (HSL / Dark Mode / Gradients), hindari warna dasar polos.
2. **Tipografi Modern**: Gunakan font modern (seperti Inter, Roboto, Outfit) bukannya font browser default.
3. **Visual Feedback**: Sediakan status interaktif (hover effect, loading spinner, error feedback, disabled state).
4. **Responsif**: Pastikan tata letak fleksibel untuk berbagai ukuran layar.
5. **No Basic MVPs**: Ciptakan tampilan yang memukau dan terasa canggih sejak pandangan pertama.
