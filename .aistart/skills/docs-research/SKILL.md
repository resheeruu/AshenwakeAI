# Documentation & Web Research Skill 🌐

Gunakan instruksi ini saat membutuhkan informasi API atau library terbaru:
1. **Targeted Search**: Gunakan `web_search` dengan query spesifik (misal: "Express js v5 breaking changes" atau "Hono route parameters example").
2. **Baca URL Docs**: Panggil `read_url` pada tautan dokumentasi resmi untuk membaca spesifikasi dan contoh kode terkini.
3. **Sintesis Teruji**: Terapkan contoh kode sesuai versi pasti dari library yang digunakan di proyek.
