# Execution Planning & Task Breakdown Skill 📋

Gunakan instruksi ini saat merencanakan tugas kompleks:
1. **Analisa Kebutuhan**: Pahami dengan jelas tujuan utama dan batasan arsitektur sebelum memodifikasi kode.
2. **Identifikasi Modul**: Tentukan file apa saja yang akan dibuat, diedit, atau dites.
3. **Pecah Sub-tugas**: Buat alur kerja berurutan yang logis dan terisolasi.
4. **Gunakan update_plan**: Panggil tool `update_plan` dengan array daftar tugas agar progress tampil transparan di terminal UI.
5. **Klarifikasi Ambigu**: Jika ada persyaratan yang meragukan, panggil `ask_user` untuk meminta konfirmasi pengguna.
